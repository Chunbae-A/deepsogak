# deepsogak

딥소각 — 2026 K-디지털 트레이닝 해커톤 (팀 춘배) 딥페이크 탐지·대응 서비스

이 리포는 **데이터셋 수집·전처리 파이프라인** 전용이다. AI/백엔드/앱 코드는 별도 리포로
분리될 예정이며, 이 리포는 학습·검증에 쓰이는 데이터를 받아오고 정리하는 스크립트만 다룬다.

- 데이터 수집 계획 및 데이터셋별 신청 링크·라이선스: [`data` 브랜치](../../tree/data) 참고
- 팀: 김경민(AI·인프라), 김다애(백엔드), 최현준(앱)

## 브랜치 구조

- `main`: 리포 소개만 유지
- `data`: 데이터셋 다운로드/전처리 스크립트, 데이터 수집 계획 문서
